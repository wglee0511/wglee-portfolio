| Electron | ❌ 없음 |
| Next.js | ❌ 없음 |

이건 **이력서가 틀렸다는 뜻이 아니라**, 그 기술들이 다른 저장소(고객 대면 앱, 온라인 스토어 웹, 프론트 단말기)
경험일 가능성이 높다는 뜻입니다. **"어느 프로젝트에서 쓰셨죠?"에 저장소 단위로 답할 수 있게** 매핑해 두세요.

**⚠️ 가장 중요한 것 — 커밋 히스토리가 없습니다.**
`payhere-pos-rn`에는 커밋이 1개(`chore: 세팅`)뿐입니다.
즉 **어느 코드가 본인 작업인지 코드로 증명되지 않습니다.**
본인 기여를 ① 처음부터 만든 것 ② 크게 고친 것 ③ 읽고 이해만 한 것 으로 나눠서
면접 시작 시 스스로 선언하고 들어가세요. 자세한 문장은 `06_payhere_pos_answers.md` 맨 위에 있습니다.

```
android/app/debug.keystore
package.json                # CodePush 배포 키가 스크립트에 하드코딩
```
